# LR_Model

This repository contains a Jupyter Notebook implementation of a Linear Regression model. The notebook walks through the steps of loading data, preprocessing, building a linear regression model, training it, and evaluating its performance.

* Data loading and inspection
* Exploratory Data Analysis (EDA)
* Feature selection and preprocessing
* Linear Regression model building using sklearn
* Model training and evaluation
* Visualization of results

### The notebook includes visualizations and evaluation metrics such as:
* Regression line plots
* Mean Squared Error (MSE)
* R2 Score
